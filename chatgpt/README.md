# Spectra for ChatGPT

Live, read-only Spectra data in ChatGPT through the hosted Spectra MCP server at `https://mcp.spectra.finance/mcp`: fixed rates, yield opportunities, markets, MetaVaults and wallet positions. It needs no account or API key.

The plugin cannot sign, send or execute transactions. APYs are percentages with the time they were read; a fixed rate holds only if the Principal Token is held to maturity, and no rate is guaranteed. This is information, not financial advice.

The `spectra-yields` skill explains how to find, compare and present the data.
